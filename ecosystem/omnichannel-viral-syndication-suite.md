### The Synchronous Anti-Pattern
In a traditional synchronous setup:
\`\`\`
User Message ➔ ManyChat ➔ [POST /api/score-lead] ➔ LLM (6s) + CRM (5s) ➔ CRASH (11s > 10s)

### The Decoupled Event-Driven Pattern
Instead of holding the HTTP connection open while your LLMs and enrichment APIs execute, decouple the intake using an asynchronous webhook queue pattern in **n8n**:

\`\`\`
1. Inbound Ping: ManyChat ➔ n8n Webhook Node

2. Asynchronous Execution:
   - Node 1: Apollo.io API enrichment

3. Push Notification:
   - Node 4: HTTP POST to ManyChat API (/fb/page/setCustomField or /fb/sending/sendContent)
\`\`\`

In n8n, configure your Webhook node with:
\`\`\`json
{
  "parameters": {
    "httpMethod": "POST",
    "path": "manychat-inbound",

    "responseData": "allEntries"
  }
}
