## Important — read this first
The page itself gives only: rank, name, DR, URL, and for the top 10 a short meta note.
It does NOT give, per site: approval time, dofollow / nofollow, free / paid, reciprocal link / badge required, or guest-post rules.
So the tiers below are classification by site type, not verified per-site facts from that page.
At submission time in the VM, Mikey must verify each site live: is it free, is it instant or reviewed, is the link dofollow, and does it ask for a reciprocal link / badge / payment. Do not report a link as dofollow until the live page is checked.

Also: the page calls these "DoFollow" links. That claim is not verified per site. Many profile / community links on this list are normally nofollow or user-generated. Treat them as profile / discovery links unless the live rel attribute says dofollow.
