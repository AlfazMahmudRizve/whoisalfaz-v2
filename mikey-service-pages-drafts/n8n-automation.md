## Who it is for

For agencies and scaling businesses that spend staff time on manual data entry, copy-paste work between sheets, and CRM updates. The main services page describes this work for agencies that want to remove manual data entry and for teams that use a CRM.

## The problem

Manual data entry and repeat admin tasks take time from strategy and sales. The n8n service page states the problem plainly: every hour a team spends copying data between sheets or updating CRM fields is an hour not spent on strategy and sales. Leads can also be contacted late, and reports made by hand can contain errors.

## What is delivered

Work is scoped per client. Based on the site, delivery can include:

- Custom n8n workflows built for a specific manual task
- Lead qualification steps inside a workflow
- CRM sync, so lead and contact data moves between tools without manual copying
- Automated reporting steps, so reports are generated from the workflow rather than made by hand
- A workflow built to run on its own after handover, with the steps and tools used listed for the buyer

No specific workflow, tool, or result is promised here. The exact workflow is agreed after the audit step below.

## Process in 4 steps

1. Discovery and audit. Review the current manual steps, the tools in use, and where time is lost.
2. Draft strategy. Set out the workflow to be built, the tools it will connect to, and what a finished run should do.
3. Solution build. Build and test the n8n workflow against the agreed steps.
4. Final and support. Hand over the workflow with notes on how it runs. The main services page states that projects come with 30 days of free monitoring, followed by monthly maintenance packages. Confirm the current support terms before this page is published: TODO-Alfaz.

## What the buyer must provide

- A short description of the manual task to be automated
- A list of the tools in use, including CRM and any forms, sheets, or messaging tools
- Access to those tools for build and testing, or a named contact who can grant access
- One contact for decisions and for testing the finished workflow
