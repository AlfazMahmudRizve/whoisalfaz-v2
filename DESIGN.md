## Phase 2: Art Direction System

### Palette (Tech Precise / High-Contrast Telemetry)
- `--ground`: `#060709` (Obsidian substrate) / `#fafbfc` (Architectural white mode)
- `--ink`: `#f3f4f6` (High-legibility titanium) / `#0d1117`
- `--muted`: `#8a919e` (Instrument grey)
- `--line`: `rgba(255, 255, 255, 0.08)` / `rgba(0, 0, 0, 0.08)` (Structural laser grid)
- `--accent`: `#00ff87` (Telemetry signal emerald / neon mint)
- `--accent-purple`: `#a855f7` (Logic node violet)
- `--curtain`: `#020304`

### Typography
- **Display:** `Urbanist` / Neo-grotesk at `64px` to `140px`, tracking `-0.04em` to `-0.06em`, uppercase, leading `0.88` to `0.92`.
- **Body:** `Inter` at `16px` to `18px`, leading `1.55`.
- **Telemetry / Metadata:** `JetBrains Mono` / monospace at `10px` to `13px`, uppercase, tracking `0.15em`.

### Grid & Composition Plan
- Strict 12-column architectural layout with hairline dividers.
- Vertical anchor lines on columns 1, 5, 9.
- Four-Corner Frame:
  - Top Left: `WHOISALFAZ // RUNTIME V2.4`
  - Top Right: `SYSTEM TIME [DHAKA: UTC+6] // STATUS: NOMINAL`
  - Bottom Left: `SPEED: 0.04s EDGE CACHE // NEXT.JS 16`
  - Bottom Right: `TACTICAL DISPATCH [CALENDAR ACCESS ↗]`

### Section Layout Families
1. **Section 1: Poster / Split Hero (Col 1-7 Display Headline, Col 8-12 Live Telemetry Cockpit)**
2. **Section 2: Statement Manifesto (Full-width 10-col architectural declaration)**
3. **Section 3: Index List with Cursor Preview (Obys-style interactive project showcase with live metrics)**
