## ⚡ Instant Execution (Zero Install)

Run directly from any terminal using `npx`:

```bash
npx alfaz-cli
```

This will render an interactive terminal business card with direct links to Alfaz's consulting services, technical guides, and contact channels.

---

## 🔍 Technical Website Audit Engine

Audit any URL directly from your command line for Core Web Vitals, SSL certificates, DNS health, and security headers:

```bash
npx alfaz-cli audit https://example.com
```

### What It Benchmarks:
* **Core Web Vitals & Real Performance:** FCP, CLS, TBT, and TTFB.
* **SSL Certificate Validity:** Cipher grade, SAN domains, and expiration countdown.
* **Security Headers:** HSTS, CSP, X-Frame-Options, and X-Content-Type-Options.
* **DNS Resolution:** Root DNS, A/AAAA records, and server connectivity.
* **Meta Tags & Social Cards:** Title length, meta descriptions, and OpenGraph/Twitter previews.

Every audit generates a live interactive web report hosted on [whoisalfaz.me/audit/](https://whoisalfaz.me/audit/).
